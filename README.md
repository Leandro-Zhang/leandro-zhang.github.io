# Lehan Zhang | Personal Academic Homepage

This is the source code for my personal academic homepage, deployed via **GitHub Pages**.

🌐 **Live Site**: [https://lehanzhang2004.github.io/lehanzhang](https://lehanzhang2004.github.io/lehanzhang)

## Features

- 🎓 Clean academic style
- 🌐 Bilingual support (中文 / English)
- 🌙 Dark / Light mode
- 📱 Fully responsive design
- 📄 CV download
- 📚 Publications with year filter
- 🔗 Google Scholar, ORCID, GitHub, Email links

## Tech Stack

Pure HTML + CSS + JavaScript. Zero dependencies.

## Getting Started

Simply open `index.html` in your browser, or serve with any static server:

```bash
python3 -m http.server
```

## Customization

1. Replace `assets/images/photo.jpg` with your own photo
2. Replace `cv.pdf` with your actual CV
3. Update content in `index.html` (search for placeholder text like "某某大学", "University Name", "lehanzhang@example.com")
4. Update your Google Scholar, ORCID, and GitHub links in the Hero section
